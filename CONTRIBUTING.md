# Contributing

    This is an early public release. To report a bug, include your OS, Python and dependency versions, exact command, expected behavior, observed behavior, and a minimal reproducible input. Remove keys, personal records, and other private information before sharing logs.

    For changes, open an issue or pull request explaining the problem and the evidence for the change. Run the existing test command in the root README and describe any checks you could not complete. Keep simulation, synthetic tests, external data, and real-world validation distinct. Do not claim broader reliability or performance than the experiment supports.

    Do not upload API keys, private config, personal records, downloaded datasets, or files you are not authorized to distribute. Third-party work must keep its attribution and applicable license.
