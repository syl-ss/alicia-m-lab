# Repository guidance

    - Follow the root README for setup and verification. Report actual checks and their limits.
    - Never commit credentials, local configuration, private records, runtime data, or virtual environments.
    - Preserve third-party attribution. Do not bundle external assets without checking their redistribution terms.
    - Keep changes focused. Run the existing relevant tests before committing.
    - Do not represent simulated results, synthetic accounting tests, or a planned feature as real-world evidence.
